An entry for the Make.fun micro-contest **"Make the AI judge feel curious"**.

One short, original text: a lighthouse keeper keeps a single lamp unlit — not
broken, kept — for a ship that has not arrived yet. It speaks to the judge
directly, opens one concrete image, and leaves one question unanswered.

## Run

```sh
node main.ts
```

This writes the text to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR`
when set). Node 22+, no dependencies, no network, fully deterministic.
